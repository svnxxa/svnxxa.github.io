# Retro Arcade Personal Portfolio

Welcome to the source code for my personal portfolio! This is an interactive, retro-arcade-themed website built to showcase my background in software engineering, data science, and machine learning. 

You can view the live site here: [svnxxa.github.io](https://svnxxa.github.io)

## About the Project

I wanted a space that was more fun and interactive than a standard black-and-white resume. This project combines my love for retro aesthetics with modern web development. It features a custom CSS layout, pixel-art styling to display my background and projects.

### Key Features

* **Retro UI/UX:** Custom CSS styling with arcade-style fonts, pixel borders.
* **Interactive Elements:** Hover tooltips, clickable project folders, and a built-in resume viewer.
* **Responsive Design:** Optimized to look good on both massive desktop monitors and mobile screens.
* **Easter Eggs:** (Try to find the secret cat popup!!! This is my favorite feature.)

## Tech Stack

* **Framework:** [React.js](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** Pure CSS (Custom variables, flexbox, and grid layouts)
* **Deployment:** GitHub Pages (`gh-pages`)

## Local Setup
1. Clone the repo
```bash
git clone https://github.com/svnxxa/svnxxa.github.io.git
```

2. Navigate into the directory
```bash
cd svnxxa.github.io
```

3. Install the dependencies
```bash
npm install
```

4. Start the development server
```bash
npm run dev
```

5. Open `http://localhost:5173` in your browser

6. Deployment: This project is configured to deploy automatically to GitHub pages. To push a new build live, run:
```bash
npm run deploy
```
(Note: This compiles the code into the `dist` folder and pushes it to the `gh-pages` branch)
